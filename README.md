# QuizShow English Bundle

This folder contains the translated app, build scripts, and platform guides.

## Quick start

- Windows: read `GUIDE_WINDOWS.md` and use `run_windows.bat` or `build_windows.bat`.
- Linux: read `GUIDE_LINUX.md` and use `run_linux.sh` or `build_linux.sh`.
- macOS: read `GUIDE_MAC.md` and use `run_mac.sh` or `build_mac.sh`.

## Included files

- `quizshow_app_en.py`
- `requirements.txt`
- `requirements-build.txt`
- Build and run scripts for Windows, Linux, and macOS
- English guides for each platform
